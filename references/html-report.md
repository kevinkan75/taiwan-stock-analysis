# 離線互動研究報告（技能1.15.0／呈現器1.1.0，實驗功能）

## 觸發與界線

僅當使用者要求「匯出互動報告」「分析台積電，並匯出互動報告」「將剛才的分析匯出互動報告」或明確要求HTML時，才執行本流程。一般「分析台積電」仍輸出既有文字與JSON，不自動產生HTML、不建立網站。

首版只支援單一普通股／ADR的快速或詳細研究，來源為通過預設驗證的個股JSON與review schema 1.2。ETF、多檔比較、市場快照及決策八關互動介面尚未支援；若同時要求決策，先正常交付決策文字／JSON，說明HTML目前不支援，不移除決策欄位或改動模式來繞過限制。

## 匯出流程

1. 找到同一次研究與作業紀錄的原始檔案，核對標的及資料截止時間。只有正文、缺研究JSON或缺review時，依原研究流程建立當次紀錄；無資料或無法完成驗證就說明缺少的檔案，不從正文擷取數字、不套合成範例補值、不改寫舊紀錄。
2. 用預設驗證檢查來源；不可用 `--derive` 當最終驗證。`html_export.py`內部也會執行同一review_guard驗證，含研究分數、報告雜湊與研究檔位元組綁定。研究與review規則1.13.0的有效舊檔可原樣匯出，來源版本不改成1.14.0；review 1.0／1.1不自動補成1.2。
3. 以同一檔名主幹、完整時間戳產生 `.html`；不得存到技能資料夾。程式拒絕覆寫已有檔案，應另取新檔名。執行：

```bash
python3 scripts/html_export.py --research /absolute/path/2330_YYYYMMDDTHHMMSSZ.json --review /absolute/path/2330_YYYYMMDDTHHMMSSZ.review.json --output /absolute/path/2330_YYYYMMDDTHHMMSSZ.html
python3 scripts/html_export.py --research /absolute/path/2330_YYYYMMDDTHHMMSSZ.json --review /absolute/path/2330_YYYYMMDDTHHMMSSZ.review.json --verify /absolute/path/2330_YYYYMMDDTHHMMSSZ.html
```

以上腳本路徑相對於技能根目錄；在其他工作目錄執行時換成已確認的技能絕對路徑。Python 3.8以上，只使用標準函式庫。無Python時保留文字版並說明未產生HTML，不宣稱人工版本已通過程式檢查。

4. 保存來源JSON、review與HTML至使用者指定或平台持續保存的位置，交付HTML下載連結。說明資料截止日與未解決限制；匯出時間不是行情更新時間。若平台預覽不執行腳本，下載後用瀏覽器開啟；未啟用JavaScript時仍可讀全部章節與表格。

## 行動裝置與原生章節連結（呈現器1.0.1）

- 使用原生頁內連結作為四個章節入口，JavaScript未啟動時保留四章全文；成功初始化後再啟用分頁、指標切換及圖表／表格控制。
- 手機寬度760px以下將表格每列改為直式卡片，以各儲存格的data-label保留欄名，不依賴橫向捲動才能讀到來源及口徑。桌面容器上限1440px，1180px以下的證據卡片採單欄；手機證據欄名與內容上下排列。
- 保留按鈕、連結及summary的鍵盤焦點提示；章節容器不再整區顯示橘框。列印入口先提供原生操作說明，iPhone／iPad使用分享選單的列印功能；腳本啟動後另提供開啟列印按鈕。
- 2026-10-16使用者確認單一個股報告mobile-v4的iPhone章節連結與版面符合預期。共用模板移植為1.0.1；此確認不涵蓋其他裝置、所有預覽器、完整鍵盤、圖表互動或列印。

## 固定呈現規格

### 呈現器1.1.0：論點對照及查核階段

- 概覽加入五欄多空論點對照。支持依據只讀明確綁定`research:/thesis/i`的主張及其premises；反方與失效條件按thesis_index分組。顯示主張id、判斷、採用理由及已選來源定位；不把反方證據誤當支持依據。缺連結直接標示，不回寫舊檔。
- 風險與來源加入查核階段表，逐項顯示實際任務狀態、理由與嘗試紀錄，另列年度財務、主張與反方及結構驗證。查核完成、取數成功、證據充分各自呈現；關鍵未解決項目保留原識別碼。
- 沿用原生章節連結、手機卡片表格、純文字跳脫、離線CSP及完整列印；不新增模型API、外部資源或瀏覽器評分。新增表格列印時納入全部內容。
- 研究技能版本為1.15.0，規則維持1.14.0，review仍為schema 1.2，呈現器為1.1.0。舊HTML需使用原呈現器版本驗證，不改寫成新版本；相同舊來源可另產生新版HTML。
- 1.0.1的既有iPhone確認僅適用當時報告；1.1.0新增對照與查核表格須另行確認，不推定已實機驗收。

| 分頁 | 內容與互動 |
| --- | --- |
| 概覽 | 原摘要四行、原訊號／總分／暫定與信心、六面向及可展開證據、多空論點對照與限制 |
| 三年財務 | 九項指標切換、SVG圖／資料表切換、完整年度期間、原幣百萬金額、普通股EPS、百分比、原表輸入及來源定位 |
| 估值 | 已知報價與估值指標、歷史區間、已有模型情境及公式／假設／來源；無資料直接揭露 |
| 風險與來源 | 查核階段與實際結果、事件、風險、反方、失效條件、缺口、作業紀錄、勾稽差額與容許差額、來源網址 |

固定頁首分列分析／資料截止／行情時間／財報截止、報價與財報幣別。「結構與計算驗證」「查核作業」「證據充分性」各自呈現；驗證通過不代表外部原文真實或投資勝率。資料缺口、年度衝突與原已排定事件放在分頁外，切換不隱藏提醒。事件按資料截止時狀態呈現，不自動聲稱距今幾日或仍未發生。

數值來自已驗證JSON，年度值沿用 `assessment.financial_history`，不在前端重新評分。顯示兩位小數與明確單位，原始精度留於來源與詳細資料；null不改成0、不跨缺值連線，不虛構第三年，ADR財報EPS不自動轉為ADR報價幣別。

單檔嵌入CSS、JavaScript與SVG，不含CDN、遠端字型、行情抓取或連線請求。來源文字／完整原始報告以安全文字呈現，只將合法http/https網址設為可點連結，其他協定保留純文字。CSP固定腳本與樣式雜湊並禁止外部資源。鍵盤方向鍵／Home／End可切換分頁；狀態同時有文字，不只靠色彩。手機規格為單欄及帶欄名的直式卡片表格；較寬裝置保留原表格與必要的橫向捲動。

列印規格為全部四章、九項圖表與年度資料表、來源、限制及完整原報告；隱藏控制項，列印事件先展開詳細內容，再恢復原畫面。不得只列印當前分頁。仍須在實際瀏覽器確認分頁、紙張與換行；程式驗證不能代替視覺驗收。

## 一致性與驗收

匯出會記錄研究／review位元組SHA-256、原報告SHA-256、來源各版本、呈現器版本、模板指紋與匯出時間；`--verify`用同版模板與相同來源重建並逐字比對，連可見表格被改動也會拒絕。此為一致性檢查，不是數位簽章或來源真實性證明。模板或呈現器改版後須使用對應版本驗證，不能把不一致直接修補成通過。

執行 `python3 tests/check_html_export.py` 驗證完整／部分／衝突、空年度、缺值、資料綁定、來源未改動、舊版本、注入與篡改拒絕。維護時另以實際瀏覽器驗收離線、分頁／鍵盤、手機、停用JavaScript與完整列印；已確認範圍依上方實機紀錄標示；其餘無法執行者列明未驗收，不標成全數通過。
