# 市場模式與市場快照（market-1.0，第一階段）

市場快照回答「現在的市場環境如何」，不回答「大盤會漲還是跌」。它供決策模式第4關、個股漲跌歸因及族群篩選共用，不進入研究評分。第一階段只支援台股；美股決策模式第4關仍按decision.md自行查核。

## 觸發與用途

- 使用者要求「分析大盤」「台股行情」「市場環境」「現在市場怎麼樣」時，執行市場模式並輸出市場快照。
- 決策模式第4關優先使用同一交易日的有效市場快照；沒有就當場建立並保存。
- 研究模式不讀市場快照，直到研究評分完成（見下方「盲測順序」）。

## 盲測順序

1. 讀取有效產業快照（industry-indicators.md），用於產業面向。
2. 完成個股研究評分；此階段不讀市場快照，也不以大盤漲跌調整任何研究分數。
3. 評分完成後才讀市場快照，用於漲跌歸因、相對強弱及決策模式第4關。

## 第4關指標（燈號只用這4項）

| 指標 | 不利的預設判定 |
| --- | --- |
| 加權指數相對240日線乖離 | 低於0（跌破年線），或高於+20%（過熱） |
| 美國10年債殖利率近期方向 | 近20個交易日上升超過25個基點 |
| 外資近5–10日買賣超 | 近10個交易日累計淨賣超，且多數交易日為賣超 |
| 成交量異常 | 下跌日成交值達20日均值1.5倍以上（帶量下跌） |

燈號與decision.md第4關相同：已確認兩項以上不利🔴；其餘若4項任一缺值⚪；4項齊備時一項不利🟡、零項不利🟢。缺值不作中性。上述判定為預設值，未經回測；分析者不得自行放寬，若改用其他判定須在報告寫明理由並標「非預設判定」。

**邊界值與來源矛盾（R7）。** 下列情形判定為「邊界」：
- (a) 同一指標的兩個來源數值分居門檻兩側；
- (b) 數值距門檻±10%以內（例：25bp門檻的22.5–27.5bp；+20%過熱門檻的+18%至+22%；成交值1.5倍門檻的1.35–1.65倍；外資賣超日數恰為半數）；門檻為0的指標（如跌破年線）沒有±10%區間，只適用(a)與(c)；
- (c) 只取得近似值（如月變化代替20交易日），且近似值落在(b)區間。

邊界指標一律以較不利一方計入燈號，燈號旁標「含邊界指標」，並列出兩個數值、來源，以及「若改判中性則燈號為X」。美債20交易日變化以日資料計算為原則；只有月變化時標「近似」。

## 市場狀態標籤

| 標籤 | 條件 | 第4關燈號 |
| --- | --- | --- |
| 有利／中性 | 4項齊備且皆非不利 | 🟢 |
| 不利 | 4項齊備且1項不利 | 🟡 |
| 明顯不利 | 已確認2項以上不利，其他項可缺值 | 🔴 |
| 待確認 | 不利未達2項，且有必要指標缺值 | ⚪ |
| 恐慌（附加警示） | 加權指數單日跌幅達3%以上；台指VIX門檻待查證歷史分布後訂定，訂定前只列數值不據以判定 | 依上列燈號，另加「個股相關性升高，大盤主導」警示 |

標籤是描述，不是預測。報告不得寫「大盤將上漲／下跌」。

## 族群強弱（研究候選清單）

- 以證交所類股指數近20個交易日報酬減加權指數同期報酬排序，列前5與後5個族群。
- 只列族群，不列個股；標「研究候選清單，非推薦」。
- 強弱是動能描述，不代表族群基本面較佳；後續仍須按個股或ETF流程研究。

## 有效期限與失效

| 用途 | 有效期限 |
| --- | --- |
| 決策模式第4關 | 只限快照所屬的同一交易日 |
| 漲跌歸因、族群篩選等參考用途 | 5個交易日 |

發生下列任一事件，快照立即失效，不論是否到期：聯準會或台灣央行利率決議、台積電法說會、加權指數單日漲跌達3%以上、重大地緣政治或政策事件。

**使用前檢查。** 技能不做背景監控。使用既有快照前，先確認期限，再搜尋快照日期之後有無上述事件；有就重做。此檢查的搜尋計入cost_log。過期快照只能作歷史參考，不得形成「目前」結論。沿用時另核對4項完整性，缺值不得沿用先前把未知當中性的綠／黃燈。

## 相對強弱與Beta（個股報告欄位）

- 相對強弱：個股近20／60個交易日報酬減加權報酬指數同期報酬，單位百分點。只取得加權價格指數時標「基準為價格指數，未含息」。至少需61筆連續可比日線。
- Beta：近240個交易日日報酬對加權報酬指數日報酬的共變異數÷基準變異數。不足240筆記null，不以短序列硬算。
- 兩項存為metrics額外鍵 `relative_strength_20d`、`relative_strength_60d`、`beta_250d`（鍵名第一階段沿用舊名，basis註明「240筆」；第二階段改為 `beta_240d`），保留完整來源欄位；放在技術面與決策層說明，不計入研究分數。第一階段finance_math.py尚無對應函式，可用其他可驗算工具並在basis註明公式與「未經技能腳本」。

## 市場快照輸出與存檔格式

1. 標題列：市場（第一階段僅TW）、資料交易日、分析時間（含時區）、「市場模式第一階段，未經程式驗證」。
2. 市場狀態：標籤與第4關燈號，逐項列4項指標的數值、判定、資料日期與來源。
3. 補充指標：數值、方向、資料日期（月資料標資料月份與公布日）。
4. 族群強弱：前5與後5族群及相對報酬，標「研究候選清單，非推薦」。
5. 有效期限與失效條件、cost_log、關鍵缺口。

不寫漲跌預測，不列個股名單。

## 成本紀錄

市場快照與產業快照JSON記 `cost_log`：`searches`、`fetches`、`reused_snapshots`（沿用的快照檔名）及 `note`。個股快照schema 1.5不接受新頂層欄位，第一階段改在個股報告末行以「本次查詢：搜尋N次、讀取M次；沿用快照：…」呈現。試跑5次以上後比較有無快照的差異，再判斷是否真的節省；未比較前不得宣稱已節省。

## 第一階段限制

市場與產業快照不交snapshot_guard，JSON標 `validated: false`，報告標「市場模式第一階段，未經程式驗證」。
