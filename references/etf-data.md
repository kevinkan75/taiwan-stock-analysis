# ETF資料來源與口徑

一般原則沿用 [資料來源與口徑](data-and-methods.md)：優先發行商與交易所原始資料，以網頁讀取工具開原始頁面，不只憑搜尋摘要；每筆保留來源、期間、口徑；財經入口網站只作交叉核對或最後替代並標明。該文件的個股核心metrics（EPS、ROE、FCF等）不適用ETF本身，改用下方ETF核心數據；成分股財務仍依其口徑。

## 來源優先順序

| 資料項 | 台灣ETF | 美國ETF |
| --- | --- | --- |
| 基本資料、追蹤指數、費率、終止條件 | 投信官網、公開說明書 | 發行商官網、prospectus |
| 每日持股與權重 | 投信官網每日申購買回清單（PCF） | 發行商daily holdings |
| 淨值、市價、折溢價、規模 | 證交所／櫃買中心ETF專區、投信官網 | 發行商官網 |
| 總費用率 | 投信投顧公會統計、基金年報 | prospectus的expense ratio |
| 追蹤差距 | 投信官網績效（基金含息vs指數含息） | 發行商績效頁 |
| 配息與配息組成 | 投信配息公告（含收益平準金比例）、集保 | 發行商distribution頁、Section 19(a) notice |

| 成分股財務 | 公開資訊觀測站 | SEC EDGAR、公司IR |
| 換股審核與生效日 | 指數公司公告、投信公告 | 指數公司公告 |

## ETF核心數據

| 指標 | 口徑 |
| --- | --- |
| 市價、淨值、折溢價 | 同一交易日；折溢價＝市價÷淨值−1，另列近20日平均絕對值與極值 |
| 規模 | 標資料日期與來源；註明是否含當日申贖 |
| 20日均成交值 | 成交金額平均，不用成交張數 |
| 總費用率 | 最近完整年度；經理費、保管費級距另列，不以級距費率代替總費用率 |
| 追蹤差距 | 見下方公式；列近1年及近3年年化 |
| 前十大與單一最大權重 | 持股日期；季度換股公告後、生效前以生效後名單為準並註明 |
| 加權P/E（或P/B） | 指數公司公布值或自算值，標來源類型及覆蓋權重 |
| 近12個月配息與殖利率 | 實際已支付配息÷現價；年化最近一次配息另列，不混用 |
| 配息組成 | 股利／利息、資本利得、收益平準金各占比，標配息期別 |
| 最大回撤 | 近3年，含息淨值序列；另列回到前高所需交易日數 |

每筆記錄沿用 `value, unit, currency, period, as_of, actual_or_estimate, basis, source_url, retrieved_at`；未知用null，不適用與缺資料分開。

## 底層估值計算

指數公司factsheet有公布本益比時優先採用，標「指數公司公布值」。沒有時自行計算，採盈餘殖利率加權（等同組合總市值÷總盈餘），避免高本益比或虧損股扭曲：

```
PE_ETF = 1 ÷ Σ( w_i × E_i ÷ P_i )
```

w為成分股權重，E÷P為各成分股TTM盈餘殖利率，虧損股以負值計入；權重以有資料的成分股重新標準化。覆蓋權重≥80%才可用於band_position；70%–80%只能用於relative_valuation並標低覆蓋；<70%不計算。

歷史區間：36筆以上月度序列，或資料商、指數公司公布的3年以上區間（標「未自行重算」）。ETF模型不以歷史持股自行重算區間；沒有公布區間時band_position記null，由暫定訊號機制處理，報告列為關鍵缺口。

## 追蹤差距與回撤

```
TD_年化 = R_基金含息 − R_指數含息
```

以完整年度計算，最多取近3年平均；指數須用含息報酬指數，與基金同幣別。主動式改算相對基準的扣費後超額報酬。最大回撤以含息淨值序列計算；只有市價序列時標「市價口徑」。

## 交付前核對（ETF追加）

債券修正存續期間的一階敏感度公式依[聖路易聯準銀行說明](https://www.stlouisfed.org/publications/regional-economist/april-1996/investment-improvement-adding-duration-to-the-toolbox)。只用於小幅殖利率變動的近似；持有期間、信用利差、曲線與凸性仍須另外分析。輸入變動用百分點，1個百分點填1，價格變動用百分比，兩者不得混作小數比例。

- 市價與淨值為同一交易日；折溢價用同日數字。
- 分割、反分割前後的價格與配息已調整至同一基準（例如0050於2025年6月一拆四）。
- 持股權重日期與成分股財報期間已標明，兩者相差超過一季時註記。
- 殖利率標明是近12個月實際配息或年化最近一次配息。
- 總費用率與級距經理費分開；同類比較使用同一年度口徑。
- 子類型調整已列替代指標、閾值與理由。
