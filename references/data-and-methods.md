# 資料來源與口徑

## 來源優先順序

| 用途 | 台灣市場 | 美國市場 |
| --- | --- | --- |
| 識別、行情、公司行動 | 證交所、櫃買中心、公司公告 | 上市交易所、公司投資人關係、具時間戳行情來源 |
| 歷史估值區間 | 自行由交易所歷史行情計算；或資料商河流圖（如Goodinfo本益比／淨值比河流圖），須標資料商與期間 | 同左 |
| 財報、營收、重大訊息 | 公開資訊觀測站、公司年報與法說 | SEC EDGAR、10-K／10-Q／8-K、公司財報；外國發行人依20-F／6-K等實際申報 |
| 指引、動能 | 公司法說簡報、公告及正式逐字稿 | 公司earnings release、法說及正式指引 |
| 預估與市場反應 | 可辨識機構、期間及日期的研究或資料商 | 同左 |
| 產業與事件 | 主管機關、產業組織、相關公司一手資料；新聞補充 | 同左 |

資產負債表、現金流量表依模式區分：詳細版一律優先以網頁讀取工具直接開啟公開資訊觀測站或公司IR財報，不能因搜尋找不到就直接標未取得，須至少嘗試一次直接讀取並記錄結果。快速版只要報告出現任何報表衍生內容（見SKILL.md「依賴的定義」）就須執行同樣要求；選擇不讀者，依該定義先清空並標「未核對完整報表」，不得以「不影響結論」代替清空。搜尋摘要通常沒有這些數字，只用來定位原文。使用官方資料檢核關鍵財務數字；行情或共識無法取得一手資料時，標示資料商與口徑，不假稱由官方驗證。不得把單一分析師稱為市場共識。搜尋摘要只用來定位原文。

從下列官方入口定位資料；每次檢查可用性，勿當成即時資料：
- [TWSE](https://www.twse.com.tw/)、[TPEx](https://www.tpex.org.tw/)、[MOPS](https://mops.twse.com.tw/)、[SEC EDGAR](https://www.sec.gov/edgar/search/)。
- [TWSE本益比及殖利率口徑](https://www.twse.com.tw/en/trading/historical/bwibbu.html)：近四季資料、EPS非正時不計P/E；其殖利率定義需與自算現金殖利率區分。
- [Investor.gov P/E定義](https://www.investor.gov/introduction-investing/investing-basics/glossary/price-earnings-pe-ratio)。
- [Investor.gov 10-K／10-Q閱讀指引](https://www.investor.gov/introduction-investing/general-resources/news-alerts/alerts-bulletins/investor-bulletins/how-read)：交叉閱讀業務、風險、管理層說明及財報。官方申報不等於監管機關保證其正確。

上述支持資料及計算口徑；評分權重、閾值及燈號為自訂研究規則，未經回測，不宣稱官方認證或預測勝率。

## 來源可信度與查核狀態

可信度依「資料項目」判斷，不依平台判斷：同一平台的原始行情可信，不代表其自行推算或預估的數字可信。

| 資料類型 | 權威來源 | 可接受的替代來源 | 注意事項 |
| --- | --- | --- | --- |
| 季報、年報 | MOPS、公司財報 | TEJ、財報整理平台 | basis標查核狀態 |
| 月營收、自結 | MOPS | 新聞轉載 | 未經查核 |
| 行情、法人籌碼 | 交易所（TWSE、TPEx） | 資料商（如Goodinfo、MoneyDJ） | 是否還原權息、是否含盤中價 |
| 指數估值 | 指數公司factsheet（逐檔確認是否公布） | 資料商推算 | 標覆蓋權重 |
| EPS預估 | 可辨識機構研究（依估值操作第4點） | 單一機構預估 | 發布日期與家數 |
| 總體與景氣 | 央行、主計總處、國發會、經濟部統計處、財政部 | 新聞 | 公布日與修正值 |
| 事件與題材 | 公司重大訊息、主管機關公告（金管會、證期局、交易所處置） | 正規媒體 | 社群與AI內容只當線索 |

- **查核狀態。** 年報為會計師查核、季報為核閱、月營收與自結為公司自行申報；官方來源不等於已查核。
- **口徑優先。** 數字不一致時，先比對還原權息、盤中價、基本／稀釋EPS、增資或拆股前後股數、合併／歸屬母公司範圍；口徑不同不是來源錯誤。口徑一致仍衝突時，先採一手原始來源，再取日期較新的可比申報；列出各值、日期與採用理由，不平均。
- **預估與目標價標示。** 引用目標價或EPS預估時標機構數：單一機構寫「單一法人（機構名或報導來源）」，3家以上寫「N家機構中位數」並列發布日期。不得把單一機構寫成「法人」「市場」等泛稱，也不稱共識。
- **線索來源。** 社群文章、個人部落格、自動生成的個股文章與SEO比較文只能用來定位線索；其數字須回到權威來源核對，核對不到就不採用。同一平台的資料庫與其自動生成內容分開看待。
- **自動化取用。** 排程或程式抓取只用明確開放的來源：交易所OpenAPI、政府開放資料（政府資料開放授權）及明確提供API者（注意查詢次數限制）。不以程式大量抓取服務條款未允許的網站；付費資料庫僅在使用者有授權時使用。

## 時間、截止與最新性

- **時區。** 使用使用者時區；未設定時使用Asia/Taipei，不以執行環境UTC取代。另列行情本身的時區、交易日期、盤中／收盤及延遲狀態。截止時間以實際查詢時間為準；未取得確切時刻就只列已知日期，不編造時刻。
- **最近交易日。** 以交易日曆辨識最近已完成交易日；盤中可採最近收盤，但須明說。報價時間不明或明顯落後最近完成交易日者，不得據以形成「目前」整體結論，可呈現指定日期的歷史判斷。
- **較新申報。** 核對時確認未漏掉較新的申報或修正報告。

## 核心數據

| 指標 | 預設口徑與處理 |
| --- | --- |
| 最新股價 | 最近可驗證報價；列當地時間、幣別、交易日、收盤／盤中／盤後及延遲狀態。查詢時間不等於報價時間。前一交易日收盤應明說。 |
| 市值 | 同時點股價×對應流通在外股數；多類股或ADR先核對公司總市值範圍。不可將ADR數量當公司股數。 |
| EPS | 優先最近四季TTM稀釋EPS；基本／調整後EPS另列。四季拆股基準及股數變化須核對，優先官方TTM。 |
| P/E | 同幣別、同證券單位股價÷匹配EPS；EPS≤0標不適用。交易所計算與稀釋EPS自算可能不同，保留定義。 |
| 營收成長 | 最新季度YoY，另列TTM YoY；台股月營收另列月份及YoY，不取代季度成長。 |
| EPS成長 | 同季、同口徑YoY；比較期EPS≤0或接近零時說明虧損縮小／轉盈及實際差額，勿呈現誤導性百分比。 |
| ROE | TTM歸屬普通股淨利÷期初期末平均普通股權益；負權益不適用，回購及高槓桿補充。無法取得TTM時，可採公司公布的單季年化ROE（標「單季年化，非TTM」並列前期比較），可用於資本效率評分，但不得寫成TTM。 |
| 毛利率 | 最新季度毛利÷營收；同期比較。金融業等不適用者改用淨利差等產業指標。 |
| 自由現金流 | TTM營業現金流−現金購置不動產、廠房及設備支出；公司定義不同另列調節，確認資本支出正負號。 |
| 殖利率 | 最近12個月已支付每股現金股利÷報價；已宣布未支付及預估另列。標特別股利；勿混入股票股利。 |

另列快速判斷用的補充數據（存為metrics額外鍵）：`price_52w_high`、`price_52w_low`（附期間與是否含盤中價）、`pe_forward`（明列年度、EPS來源與家數）、`valuation_band_position`（現價倍數位於區間的位置）、產業關鍵指標（見industry-indicators.md）。

每筆記錄 `value, unit, currency, period, as_of, actual_or_estimate, basis, source_url, retrieved_at`。未知用null／未取得，不能用0。不適用與缺資料須分開。基本／稀釋、GAAP／調整後或拆股基準尚未確認一致時，只列兩期原值，不先給成長百分比再附「口徑待確認」。

新快照十項核心metrics鍵固定為price、market_cap、eps_ttm、pe_ttm、revenue_growth_q2、eps_growth_q2、roe_ttm、gross_margin_q2、fcf_ttm、cash_yield；即使未取得或不適用亦保留完整欄位、null值及basis原因，不得只輸出有數值的項目。替代指標與其他期間可另增鍵；例：金融業gross_margin_q2為not_applicable，另列net_interest_margin。calculated的pe_ttm由匹配幣別與每股／每ADR單位的price及eps_ttm驗算。

快照value保留計算精度，報告表格再四捨五入；例如精確P/E為62.639…時，不把表格62.6當成原始calculated值交驗證器。來源只有四捨五入值時明列限制，勿製造不存在的精度。

另記 `source_type`：quote（行情）、company_announcement（公司公告）、financial_statement（財報）、monthly_revenue（月營收）、preliminary_results（自結）、company_guidance（公司指引）、external_estimate（外部預估）、analysis_assumption（分析假設）、other（其他明列來源）。多來源衍生值以主類型記錄，其餘來源於sources各自分類。`value_status`為reported／calculated／estimated／missing／not_applicable；衍生值附 `formula`、`inputs`，輸入各自保留期間與來源。source_url採來源網址陣列，缺值可空陣列；已知值不得無來源，未知value用null，actual_or_estimate可null。正式財報明列查核／核閱／未查核，自結或月營收不取代正式季度財報；合併及歸屬母公司口徑另記於basis。自行算出的實際歷史值仍屬actual，不能因calculated就標成預估。

美國財年採公司財年並列實際截止日。民國年可加西元對照。季報現金流常為年初至今累計，須由可比累計相減求單季，再形成TTM，避免重複相加。遇重編採最新值並註記。新紀錄的calculated輸入鍵、情境乘積及區間current_metric依calculations.md「計算與欄位連動」填寫，使用同一批已核對數值。

## 三年年度資料

完整個股報告另依SKILL.md直接連結的financial-history.md核對最近三個完整年度、原文單位、歸母範圍、平均權益及現金支出；新增年度附檔不取代最新季報／TTM，也不因缺年度自動否決研究。

## 交付檢核

| 檢查 | 通過條件或缺口處理 |
| --- | --- |
| 市值時點 | 股價與流通在外股數同時點；僅有較早股數時顯示「估算市值」及股數日期，不以精確市值比較或排名。 |
| EPS及P/E | 使用匹配的稀釋TTM；僅有基本EPS時明標替代口徑，不稱較保守。不將季度基本EPS與其他季度稀釋EPS混加；股數／拆股變化大時說明逐季相加的限制。 |
| 成長率 | 用同期間同口徑原值重算；顯示值四捨五入可能無法重現公告百分比，先取未四捨五入基礎，未取得就註記待核對，不直接判定公告錯誤。 |
| 一次性與預估 | 報導EPS與排除一次性後EPS分列；僅移除已知項目時標「部分調整」，不宣稱全面正常化。自結、年度化及模型假設不得寫成已實現TTM。 |
| 現金流與資金 | 分別檢查營運資金占用、現金資本支出及籌資來源；負FCF不單獨證明流動性危機，籌資流入亦不證明核心獲利品質良好。檢視應收、存貨、到期義務及擴產回收條件。 |
| ROE與現金轉換 | ROE使用匹配的母公司淨利及平均母公司普通股權益，說明增資／回購造成的分母變化。合併CFO除合併淨利；若採歸屬母公司淨利，明列範圍差異，不把比例當同口徑結論。 |
| 估值推導 | 檢查所有輸入的幣別、證券單位、期間、公式及假設依據。缺可靠假設就停用相關模型價與評分，不用敏感度填補。 |

逐項保留通過／限制／未通過及處理結果；內部檢核不必全文貼入快速版，但會影響結論的限制須顯示。

## 估值操作

依資料可用性依序處理：先算已知TTM或合適的實際估值，再查歷史／同業依據，最後建立有依據的情境；不要求所有方法齊備，也不因缺外部EPS共識就停止其餘估值。依scoring.md判定估值覆蓋數與總評資格。

1. 穩定獲利企業可用P/E；金融業結合P/B及ROE；REIT參考FFO／AFFO；虧損成長股以EV/Sales、EV/EBITDA或透明假設DCF。缺合適方法不強行給價格區間。
2. 歷史區間依下列任一來源建立，並存入 `valuation.band`：
   - **自行計算**：近5年月度可比觀測，至少36筆才呈現分位；`basis` 為self_history。
   - **資料商區間**：資料商公布的本益比或淨值比河流圖、歷史區間表，須能讀到期間（至少3年）及區間數值（低／中／高或分位）；`basis` 為vendor_band，報告標「資料商區間，未自行重算」，`observations` 可為null。
   情境倍數（保守／基準／樂觀）預設取區間第25百分位、中位數、第75百分位；改用其他分位或同業（3家以上）須說明理由。區間若涵蓋明顯不同的產業週期或公司成長結構（例如過去下行週期的低倍數），在報告中註明對保守情境的影響，但不得自行剔除觀測值；是否可直接取中位須先依第11點判定。資料商只提供低點、中位、高點時，保守與樂觀情境改用「低點與中位的中點」與「中位與高點的中點」，標「近似分位」，且須與第10點並用：不得以原始（未調整）淨值配近似分位，以免保守情境反而變寬鬆。只有文章對區間的文字描述而無數值時，視為樣本描述，不得建立區間；此時情境只能列為敏感度參考，模型上行與情境韌性記null。各時點只用當時已公布EPS，不能以今日EPS重算歷史。補充週期及一次性收益。
3. 同業選3–5家業務及盈利模式相近者，列選擇理由與差異；不同GAAP／調整後或TTM／Forward不合併排名。
4. Forward P/E明列預估年度或NTM、EPS來源、發布日期及口徑。公司指引不能直接當EPS共識；沒有預估就標未取得。情境EPS可採：(a) 3家以上可辨識機構預估的中位數（`eps_basis`＝external_multi，可稱「機構預估中位數」，不稱共識）；(b) 單一機構預估（external_single，報告明標單一機構）；(c) 由公司指引推導（company_guidance_derived，列推導步驟）；(d) 第6點的分析假設。資料發布日期超過90天者另標「預估可能過時」。
5. 情境使用一致財年及幣別。列保守／基準／樂觀EPS、P/E、依據、乘積；預設6–12個月模型觀察期間，與1–3年投資論點分開。
6. 無外部預估但有充分資料時，可建「分析假設EPS」，顯示從實際基準、成長、利潤率及股數推導的步驟；不得寫成共識。沒有依據就不建數字情境。
7. 列基準模型價相對現價差距、保守情境下行及估值收縮。情境區間不可稱統計信賴區間。**估值方法衝突（R3）**：主方法依industry-indicators.md的估值主軸，交叉方法為另一可行方法。兩方法的基準模型價一個高於現價+15%、另一個低於現價−10%時，視為「方法衝突」：model_upside最高1分；comparable_valuation不得給2；專家摘要「估值位置」並列兩方法結果。判定以套用第10、11點之後的模型價為準。
8. ADR須用每ADR同幣別EPS；先驗證存託比率及匯率時點。不能把2330的TWD EPS除進TSM USD股價。拆股、增資及股利調整基準亦須一致。
9. 僅有現價時，可依明列的假設P/E反推所需EPS＝現價÷假設P/E，或呈現倍數敏感度。無歷史／同業／業務依據的倍數不是合理倍數；反推結果僅描述成長要求，不形成合理價、上行空間或估值得分。高P/E本身不足以證明高估。

10. **淨值品質檢查（R1）。** 採P/B或P/B×ROE時，符合任一條件即為「淨值品質待調整」：(a) 最近一季每股淨值變動超過±15%；(b) 近四季淨值變動中，來自其他綜合損益（金融資產評價、權益法OCI、換算差額）的部分超過一半；(c) 單一上市持股的市值占每股淨值20%以上。處理方式依序選用，並套用到保守、基準、樂觀三個情境，不得只調基準：(1) 以調整後淨值計算：扣除可辨識的評價利益；無法拆解時以近四季平均每股淨值代替，標「近四季平均，非調整後淨值」。(2) 無法取得近四季淨值：保留原淨值，但model_upside與scenario_resilience皆最高1分。(3) 連原淨值口徑都無法確認：兩項記null，報告標「淨值品質待確認」。報告列出持股重估敏感度（例：某持股每±10元→每股淨值約±0.43元）。
11. **歷史區間可比性（R2）。** 比較「TTM ROE」與「區間期間各年度ROE的中位數」。各年度ROE＝（年度歸屬母公司淨利－當年度特別股股利）÷〔（年初歸屬母公司普通股權益＋年末歸屬母公司普通股權益）÷2〕×100%；無特別股時，股利扣除項為0。分子與分母須使用相同幣別、金額單位及股東範圍，均不含非控制權益，分母亦須排除特別股權益；與TTM ROE比較時須採一致口徑。不得以總淨利除以每股淨值。無法取得匹配的期初、期末權益時，優先採用可核對期間及定義的公司正式公布年度ROE；仍無法取得則維持資料缺口，不以不同單位的數字代算。TTM ROE低於區間ROE中位數的一半時，基準倍數不得直接取中位，預設改用近似P25（低點與中位的中點）；資料不足以估算時，model_upside最高1分。也可改以P/B–ROE對應並列要求報酬率假設，但須在報告說明理由。取不到區間期ROE：標「區間可比性未確認」，model_upside最高1分。不剔除觀測值的原則保留；調整的是取哪個倍數，不是刪資料。

## 事件與風險核對

預設查最近90天，並補充仍影響論點的較早事件；列事件發生日、發布日、已發生／預定及影響。下次財報日期須查證，找不到確定日期就不填。事件的公告日／時間不得晚於資料截止；已公告的未來事件可列scheduled，截止日後才公告的內容不可回填歷史分析。日期與狀態的程式檢查見calculations.md。整理估值、營運、財務、法規、競爭、匯率與集中風險的具體傳導路徑。

## 技術資料

研究層技術燈號需**240筆以上**有效日線（約一年交易日，與market.md的240日線一致），明列調整方式及來源。不足240筆時technical.status＝insufficient_data、燈號⚪；已計算的指標可列示並標「樣本不足，僅供參考」。Beta採同一門檻。決策模式第6關在無法自行計算時，可引用最近3個交易日內的資料商指標並標「資料商指標，未自行重算」；此類指標只用於決策層，研究層技術燈號仍維持not_run或資料不足。先按日期排序、去重及處理缺列，不以0填非交易日。拆股須調整；總報酬／股息調整價不能直接當可成交支撐價。

明列SMA；RSI採Wilder平滑；MACD採EMA(12)−EMA(26)，訊號線EMA(9)。初始化可能與資料商不同，標方式。RSI極端或MACD交叉本身不等於買賣證據；交叉的描述方式見scoring.md「交叉幅度」。成交量採同股數基準，觀察相對20日均量。支撐／壓力引用實際近期高低點及期間；只有收盤資料不能假稱盤中高低價。

**驗證範圍。** 日線至少做兩項驗證並在報告列明：(1) 最近20個交易日價量對第二個來源；(2) 至少一個歷史日期的指標值（SMA、RSI或MACD）對第二來源。只有單一來源時標「單一來源，僅部分驗證」，信心最高「中」。還原與未還原的差異（如SMA120、SMA240）說明差距與原因，不當成錯誤。

**樣本內統計。** 引用「過去類似情境後的表現」時標筆數與是否互相重疊（如連續日），未滿30次不稱規律，只能寫「樣本內觀察」，並說明門檻（如量比3倍）為分析者自訂；不得當成機率或預測。
